# Archived development records

These files are point-in-time planning, review and evidence records from the
earlier nine-release milestone. They are retained for development history and
are superseded by:

- `../reference/SUPPORTED_RELEASES.md`;
- `../evidence/release-output-audit-final.csv`; and
- `../evidence/release-output-audit-final.csv.sha256`.

The current package supports all 59 actual Resources and Energy Quarterly
editions from September 2011 through June 2026.
