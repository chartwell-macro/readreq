# Support

## Where to ask

- use [chartwellmacro@gmail.com](mailto:chartwellmacro@gmail.com) for
  reproducible bugs and documentation gaps;
- include a focused example for usage questions and design proposals; and
- follow the root `SECURITY.md`; use GitHub's private advisory form when
  available, or request a private channel in a public issue without disclosing
  vulnerability details.

## What to include

Provide:

```r
sessionInfo()
packageVersion("readreq")
```

Also include the exact `release_id`, requested assets/view, parser version,
error class and a minimal example. A source URL and SHA-256 identify the exact
asset.

## Support boundaries

Support covers package behaviour, the audited role-specific surfaces recorded
for the 59 catalogued editions, cache replay, release identity and
reproducibility.
