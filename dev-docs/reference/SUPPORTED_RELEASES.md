# Supported releases

`readreq` supports every actual Resources and Energy Quarterly edition from
the inaugural September 2011 edition through June 2026.

The checked-in catalogue contains 59 audited editions:

- 57 editions expose their complete structured companion workbook tables;
- December 2011 and March 2013 expose audited Key macroeconomic assumptions
  from the official reports; and
- every edition carries exact source URLs, asset roles and release metadata.

The serialized provider certification is
`dev-docs/evidence/release-output-audit-final.csv`. It records asset hashes,
observation, series and table counts, output hashes and validation results for
all 59 editions. Every row is valid with zero unresolved duplicate keys and
zero current-view conflicts.

The evidence file SHA-256 is recorded in
`dev-docs/evidence/release-output-audit-final.csv.sha256`.
